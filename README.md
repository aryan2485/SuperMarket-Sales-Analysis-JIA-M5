# SuperMarket Sales Analysis

## Project Overview

This project analyzes supermarket sales data to identify meaningful
patterns in sales, customer behavior, product performance, payment
methods, and profitability.

## Dataset

The dataset contains 1,000 supermarket transactions with 17 variables.

Important features include:

- Branch
- City
- Customer Type
- Gender
- Product Line
- Unit Price
- Quantity
- Sales
- Payment
- Gross Income
- Rating

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- GitHub

## Analysis Performed

- Dataset exploration
- Missing-value analysis
- Duplicate checking
- Statistical analysis
- Product-line sales analysis
- Branch sales analysis
- City sales analysis
- Payment-method analysis
- Customer-type analysis
- Customer-rating analysis
- Gross-income analysis
- Correlation analysis
- Data visualization

## Visualizations

The project includes:

- Bar charts
- Pie charts
- Histograms
- Scatter plots
- Correlation heatmap

## Key Findings

The analysis identifies differences in product performance,
branch sales, customer behavior, payment preferences, ratings,
and gross income.

## Conclusion


This project demonstrates the use of Python for exploratory data
analysis and visualization of a real-world supermarket dataset.
